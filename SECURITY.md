# Security Policy

Report suspected vulnerabilities in Birch and its official plugins through [GitHub Private Vulnerability Reporting](https://github.com/BirchHQ/birch-code/security/advisories/new) in the Birch community repository.

See the [canonical Birch security policy](https://github.com/BirchHQ/birch-code/blob/main/SECURITY.md) for supported releases, scope, research rules, and response expectations. Do not disclose vulnerabilities, secrets, or private logs in public Issues, Discussions, or pull requests.
